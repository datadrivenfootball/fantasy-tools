## 2026-11-08 - JEG-1548 Visit counter (GoatCounter), off until the site code is set; connector link source tags

Decisions (Jeremy, 2026-11-08, multiple choice): a cookie-less hosted counter, GoatCounter; no consent banner (no
cookies, no personal data); events = the journey funnel plus key actions; AI link-backs tagged with a source.
JEG-1414 (the after-launch placeholder for the same work) was closed as merged into JEG-1548.

### How it works
- `app/next/analytics.js` is the only thing that talks to the vendor. **The one switch is `GOATCOUNTER_CODE` at its
  top** (empty = off). It also counts only on `HOSTS` (`datadrivenfootball.github.io`), so local copies, other hosts and
  tests send nothing. A custom domain later needs one entry added to `HOSTS`.
- `site.js` (top block) loads analytics.js async, queues `DDF.track(name)` calls until it loads, and takes a `?src=` tag
  off the address bar at once (only the src pair; the rest of the query and the `#s=` hash stay byte-for-byte), so a
  blocked analytics.js cannot leave the tag for a Bookmark link.
- Each count is one `fetch` GET to `https://<code>.goatcounter.com/count?p=<label>&e=<true|false>&rnd=<random>` with
  `credentials: 'omit'`, `referrerPolicy: 'no-referrer'`, `keepalive` (so Start fresh, which navigates away, still
  counts). Nothing else is sent: no title, referrer, screen size, query or hash. The vendor's count.js is **not** used:
  by default it sends `document.title` (which carries the league name since JEG-1564) and the query string.
- Labels are fixed: page views from the `PAGES` map (file name -> `/`, `/entry/connect`, `/entry/setup`,
  `/entry/settings`, `/workspace/team|explore|partners|find|waivers`, `/build`, `/values`, `/learn`, `/ai`); events
  from `EVENTS`: `league-added/paste|link|sleeper|manual`, `settings-confirmed`, `bookmark-clicked`, `bookmark-again`,
  `trade-message-copied`, `value-override-set`, `start-fresh`, and on the first page of a visit `visit/direct`,
  `visit/saved-link` (a #s= link with no tag: a bookmark or an untagged chat link), `visit/<client>[/<tool>]`,
  `visit/other-tag`, and `device/phone` (width < 768) or `device/desktop`. Anything else is dropped. Page code can
  report actions only (`visit/*` and `device/*` are refused from `DDF.track`). Each label is sent at most once per page.
- Nothing is sent when Do Not Track or Global Privacy Control is on. No cookies, no storage: analytics.js never touches
  `document.cookie`, localStorage, sessionStorage or IndexedDB. Every step is in try/catch.
- Footer line (only when the code is set): "What we count: which pages are opened and a few clicks (like Bookmark or
  Copy message), with no cookies and nothing about your league, teams or players. Turn on Do Not Track or Global Privacy
  Control in your browser and we count nothing."
- Hooks: site.js (bookmark click, settings confirm, `DDF.overrides.set`, Start fresh, `DDF.link.decodeBlock` = league
  added by link, connect.html forwarding carries the tag), connect-entry.js `save()` (method only), build-trade.js
  (Copy message), legacy-routes.js (carries the tag to the page an old link now opens; flags the stop page so it is not
  counted as a page view).

### Source tags (MCP, built and tested, NOT deployed)
`09-mcp-server/source/supabase/functions/mcp/source-tag.ts` adds `?src=<client>-<tool>` (e.g. `claude-find_trades`)
before the hash of every site link in a tool result (text outside fenced blocks, and structuredContent except `state`).
Client from the request User-Agent: `Claude-User` -> claude (seen in the function logs on 2026-11-08), openai/chatgpt
-> chatgpt, else ai. Deploy plan and order are in `09-mcp-server/DEPLOY.md` (deploy after this site change is live).
The repo copy `supabase/functions/mcp` is not the deployed source (JEG-1574 Todo), so it was not changed.

### For Jeremy to turn it on
1. Sign up at goatcounter.com (free) and create a site; pick a code (e.g. `ddf-fantasy`). The dashboard is then at
   `https://<code>.goatcounter.com`.
2. No "allowed domains" setting is needed: the documented /count endpoint takes counts from any page, and our
   requests carry no Referer.
3. Optional, in the site's Settings: leave Sessions on (needed for unique visitors per step); turn off collecting
   anything else you do not want (we send no referrer, title or screen size anyway; country is derived by GoatCounter
   from the IP and not stored as the IP).
4. Give the code to Claude; one line changes (`GOATCOUNTER_CODE` in app/next/analytics.js), then `make sync` and merge.

Terms (checked 2026-11-08, goatcounter.com/help/terms): free "for reasonable public usage"; personal sites and small
businesses are fine; there is no non-commercial-only clause now. Operated from Ireland; the site owner is responsible
for local data-collection law. GoatCounter keeps IP+User-Agent only in memory to make an 8-hour session id.

### Checks
- `tests/test_analytics_privacy.py` (Playwright, every request recorded at the context level): off by default on all 13
  pages with a full #s= link and a tag; every page on, with and without a league link: only `p`/`e`/`rnd`, no Referer or
  Cookie header, no league, team or player name or token in any off-host request (URL, headers, body, decoded);
  DNT and GPC send nothing; a blocked counter throws nothing; 390 and 1440 device class and no overflow; no cookies and
  no storage writes from analytics.js; key actions; tag removed even when analytics.js is blocked. A mutation that put
  the hash and query into `p` failed two tests.
- Chrome itself logs "Failed to load resource" for any blocked request (fetch, image and beacon alike, tested); no
  script can stop that line. It is the only console error allowed when the counter is blocked.
- Pre-existing off-host requests: Google Fonts on every page (fixed URLs, no league data) and the Sleeper import.
