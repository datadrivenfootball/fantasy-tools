## 2026-11-13 - JEG-1632 K and DEF slots in League settings (part 1: inputs and roster space)

Contract (Jeremy, 2026-11-13): "League settings needs to allow for inputting defense and kicker, even if we don't score
them, as they take up roster space. We need to factor this in."

### Audit
- The JEG-1539 swap dropped the K/DEF steppers the old page had (JEG-565, #645). settings.html, the link format, the
  ddf-league/ddf-engine adapters and the Sleeper import carried no K/DEF, so the engine's K/DST stayed at 1/1.
- Roster-space readers of K/DST already existed: waivers rosterSizeOf / openSlots, isRequiredSpecial, v2 league problems.
- The value engine ignores K/DEF in both twins (bench seats = teams x Bench, skill only). Whether a K/DEF slot should take
  skill bench seats is a methodology decision, posted on the ticket; not changed here.

### Changes
- settings.html: K and DEF counts (0-3, "Not evaluated", own row), counted in "N starters, M bench, T roster spots" and
  the action bar summary; saved through DDF.league.setSettings -> engine roster K/DST (ddf.v2.league-settings).
- site.js: link field `settings.kdef [k, def]` (JSON body, only when not 1/1), `DDF.link.kdefSlots`, prefill, bookmark
  settings, settings confirm. Adapters: ddf-league.js, ddf-engine.js chatLeague, connect-entry.js, legacy-routes.js,
  team.html lineup text. Sleeper import reads K and DEF roster positions.

### Verified
- tests/test_jeg1632_kdef_slots.py: convention twins (py/js bench seats) agree at K/DEF 0-3 x 8-14 teams x 1QB/SF;
  roster spots, open spots and K/DEF drop eligibility change with the slots; every DDF Value identical at K/DEF 0, 1, 3;
  Settings at 1440 and 375 (render, caps, total, save, reload); link round trip, 1/1 token identical to an old link.
- tests/test_sleeper_import.js (K/DEF counts), tests/test_jeg1571_qb_flex.py updated for the new row and total text.

### Not done
- MCP link codec (handoff 09-mcp-server, supabase/functions/mcp) does not read kdef; it ignores the field.
- Pasted rosters do not infer K/DEF slot counts (labels collide with positions); settings.html asks.
