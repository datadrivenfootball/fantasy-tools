## 2026-11-08 - JEG-1571 QB-eligible flex (superflex / QWRT) slot count

Contract: a friend's league starts QB, 2 RB, 2 WR, TE, FLEX and a QWRT flex (QB/WR/RB/TE) with 12 bench. Settings had
only a Superflex yes/no in League format (he did not find it and entered 2 QB, then 2 FLEX), and nothing could express
two QB-eligible flex slots. Add a "Flex that can start a QB (superflex)" count (0-2) that flows through Settings, link
state, the engine and the MCP reader, with existing settings byte-identical.

### What existed (audit)
- The value model already treats SUPERFLEX as a slot count: `vpAllocate` takes `teams x SUPERFLEX` QB-eligible seats
  after the dedicated slots and before FLEX; bench seats, sigma, the 2-QB rule (JEG-1366: only when SUPERFLEX = 0) and
  `usesSuperflexValues` all read the count. `value_reference.py` matches (Setting(superflex=n)).
- Lineup math on the pages (v2/finder.js `pickStarters`, used by ddf-league lineup/tiers, ddf-opportunity, ddf-why)
  fills `shape.SUPERFLEX` slots by count after FLEX; greedy in that order is optimal because FLEX eligibility is a subset.
- The limits were elsewhere: curve-widget.js and get-values `league.ts` clamped SUPERFLEX to 0-1; the link header has
  one superflex bit; every settings adapter mapped the boolean to 0/1; Settings had no count.

### Changes
- Engine: SUPERFLEX bound 0-1 -> 0-2 (curve-widget.js ROSTER_BOUNDS, get-values league.ts). No value-model.js change.
- Link (LINK-FORMAT 2.1, handoff 08-ai-module): `settings.superflexSlots: 2` in the JSON body only; written only for 2,
  so 0/1-slot tokens are unchanged; header and ID stream unchanged. `DDF.link.superflexSlots(settings)`; label
  "2 superflex".
- Adapters: ddf-engine.js `apply`/`applyVisit` take `superflexSlots` (wins over the boolean), chat league maps it;
  ddf-league.js, site.js (bookmark settings, settings confirm, link prefill), legacy-routes.js, connect-entry.js,
  team.html lineup text.
- Settings: the League format Superflex yes/no is replaced by a count control under Position counts with a helper and
  the (i) text; counted in "N starters, M bench" and the action bar summary; 44px steppers.
- Imports: Sleeper `SUPER_FLEX` count (2+ -> superflexSlots 2); pasted rosters count QB flex slot labels printed on
  their own line (Q/W/R/T, W/R/T/Q, QWRT, SUPERFLEX, SFLX, OP; league-paste.js `qbFlexSlots`, only raises, never
  sets 0); rosterparse.js / v2 roster-paste.js know the labels.
- MCP (handoff 09-mcp-server/source, not deployed): link.ts codec, `superflexSlots` tool arg, read_state carries it.
- JEG-1569: independent. This changes seat counts only; `ddf_split` (charts-only, default off) is untouched.
